## 发布流程测试

运行 `python3 -m unittest discover -s tests -p 'test_publish.py' -v`，仅需 Python 标准库和 Git。

- 新仓库与已存在空仓库的首次发布；`--check` 不进行远端写入。
- 真实 Git 的仓库本地身份检查、首次提交与普通推送。
- Tests 失败时停止；推送后重试不重复创建提交。
- Actions 使用的不带 `.git` 的 origin；拒绝其他仓库、额外推送地址和异常 URL 重写。
- 首次发布基准保护；拒绝用改动后的旧源码直接覆盖远端。
- 只发布指定 SHA 的成功测试结果；较新的失败结果、其他分支或其他提交不能通过。
- 使用真实构建产物创建标签、生成草稿、上传中断后续传及附件 SHA256 比对。
- 已正式发布的版本不可覆盖；不可变 Release 重跑只验证相同附件。
- 源码 ZIP 包含发布脚本和工作流，不包含嵌套 ZIP、Git 历史或运行数据。

测试使用临时工作仓库和本地裸仓库；Git 与 ZIP 构建实际执行，GitHub API 与网络传输使用模拟。未创建真实 GitHub 仓库或发布 Release。交付包的 0.1.0 插件文件与原安装包逐字节一致。
