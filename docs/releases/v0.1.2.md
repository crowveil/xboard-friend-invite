# XBoard Friend Invite 0.1.2

在 0.1.1 基础上增加邀请姓名／备注同步到 XBoard 用户管理，以及 Telegram 必填备注交互。

## 行为

- 网页邀请填写姓名／备注，Telegram 发送 `/new` 或点击生成邀请后按提示输入必填备注，再选套餐和期限；领取成功后将备注写入用户的 `remarks`。
- TG 备注要求 1–120 个字符的单行文本，空白、过长、非文字消息不能进入下一步。草稿 20 分钟有效，`/cancel` 可取消；重新 `/new` 废弃前一份未完成草稿。
- 保留 `/new 小林` 快捷输入；网页备注仍选填。命令不被误存成姓名，非绑定账号和已失效绑定不能填写备注，重复消息／按钮不重复创建邀请。
- 空白备注不写入，已有备注保留并追加一行。仅使用服务端保存的邀请备注，注册请求不能覆盖。
- 写入与账号注册、套餐分配、邀请核销在同一事务中完成，失败一起回滚。
- 升级前未领取的邀请也适用；已领取的历史用户不自动回填，后续在用户管理手动修改的备注不会被插件覆盖。

## 升级

备份数据库、APP_KEY 和插件目录，直接上传 `FriendInvite-0.1.2.zip` 升级，不卸载清数据。重启 Web / Octane 及后台常驻 PHP 进程，刷新控制台。无需修改 XBoard 或增加数据库表。创建一份带备注的测试邀请，领取后到用户管理检查备注。

保留 0.1.1 的资源恢复、诊断、草稿保护、配置冲突保护和 Telegram 恢复功能。

## 验证范围

新增回归覆盖备注写入、注册参数篡改、空备注、保留原备注、领取重放及写入失败的事务回滚。测试使用固定 XBoard 注册服务样本与 SQLite 测试模型；真实 MySQL、浏览器布局和 Telegram 网络仍需目标环境验收。

## 发布

源码根目录运行 `bash publish.sh --check`，然后 `bash publish.sh`，确认文字为 `PUBLISH v0.1.2`。本机无需 PHP 或 Node，Actions 测试通过后发布。既有公开版本不会被覆盖。
