# XBoard Friend Invite 0.1.0

首个公开版本。管理员在独立后台或专属 Telegram 机器人中选择 XBoard 套餐和使用期限，生成一次性注册链接。好友注册后自动获得套餐，无需付费或创建订单。

- 支持 1 天、1 个月、1 年、3 年和永久；继承套餐额度、权限组、限速与设备数。
- 保留 XBoard 原有注册校验，支持邀请过期、撤销、事务核销和重复请求保护。
- 独立管理控制台限时开放，原生插件配置页显示当前站点的控制台地址。
- Telegram 管理员绑定、套餐和期限按钮、领取通知及发送重试。
- 限时 Debug 与脱敏诊断导出。

## 安装

下载 `FriendInvite-0.1.0.zip`，在 XBoard 插件管理中上传并启用。按 README 完成注册开关、允许赠送套餐和可选 Telegram 机器人配置。

插件适用于私人与朋友使用的站点；启用邀请注册后，普通邮箱注册仅接受本插件生成的邀请。永久账号的流量重置遵循 XBoard 当前实现，详见 README。
