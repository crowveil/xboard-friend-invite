# 好友邀请 0.1.0

在独立管理后台或专属 Telegram 机器人中选好 XBoard 套餐，生成朋友的注册邀请。支持 1 天、1 个月、1 年、3 年、永久；注册后自动开通，无支付流程。

## 打开管理后台

在插件“配置”中开启“开放管理控制台”并保存，复制说明中的完整控制台地址，在已经登录 XBoard 管理员的同一浏览器打开。地址由当前站点自动生成。

后台开放 60 分钟，可延长或提前关闭。关闭网页管理不影响机器人和邀请注册。

## 首次配置

1. 在 XBoard 开放注册、开启强制邀请码注册、关闭全站试用。
2. 在独立后台“设置”勾选允许赠送的套餐，确认注册链接模板，开放好友邀请注册并保存。
3. 在“邀请管理”选套餐、期限，生成注册链接发给朋友。

启用插件后，普通邮箱注册只接受本插件生成的邀请。邀请只可供一个新账号领取一次；已有账号不会自动续期或改套餐。默认链接 7 天内可领取，套餐期限从注册成功时开始计算。

额度、权限组、限速和设备数取自领取时的 XBoard 套餐。永久账号没有到期时间，沿用 XBoard 不自动重置流量的行为。

## Telegram

向 @BotFather 创建独立机器人，在后台“Telegram”填入 Token 连接，再生成管理员绑定指令并发给机器人私聊。之后用 `/new` 选择套餐和期限，`/new 朋友备注` 附带备注，`/list` 查看及撤销最近邀请。Webhook 需要公网 HTTPS 和服务器可访问 Telegram。

只有绑定的账号可以管理；不要复用 XBoard 原有机器人的 Token。无需另外部署服务。

## 排障与维护

在“诊断”开启限时 Debug，复现后导出脱敏 JSON。确保 XBoard 原有计划任务和队列正常运行；领取通知由计划任务发送，可能延迟约一分钟。真实 Telegram 连接需要安装后验证。

禁用插件会撤销全部未领取邀请，已开通账号保留。卸载时保留插件数据表，防止误删已发放记录；不要单独删除原生邀请码记录来整理数据。数据库和 APP_KEY 应一起备份。
